🧩 1. Parsing-Phase
Ziel: Die .cub-Datei lesen, überprüfen und alle Informationen intern speichern.

🔄 Ablauf:
📄 1.1 Datei einlesen
Öffne die .cub-Datei

Lese zeilenweise

🧾 1.2 Inhalte erkennen
Unterscheide zwischen:

Textur-Pfaden: NO, SO, WE, EA

Farben: F, C

Map (alles nach den oben genannten Elementen)

📦 1.3 Inhalte speichern (z. B. in einer t_config-Struktur)
Textur-Pfade (char *north_tex, etc.)

Farben (int floor_color, int ceiling_color)

Map (char **map, int map_height, int map_width)

Spielerposition und Blickrichtung (float px, py, angle)

🧪 1.4 Validierung
Jede Information genau einmal vorhanden?

RGB-Werte gültig?

Texturpfade existieren?

Map:

Ist von 1 (Wand) umgeben?

Gültige Zeichen (0, 1, NSEW, )?

Nur eine Startposition?

🕹️ 2. Execution-Phase
Ziel: Das Spiel starten, mit Raycasting rendern und Benutzer-Input verarbeiten.

🧱 2.1 Setup
MiniLibX initialisieren (mlx_init, mlx_new_window)

Texturen laden

Farben vorbereiten

Fenster öffnen

📐 2.2 Raycasting & Rendering
Für jede vertikale Linie im Fenster:

Berechne einen Strahl (Ray)

Finde den ersten Treffer mit einer Wand

Bestimme Distanz, Wandhöhe, Textur, Texel

Zeichne diese Linie (z. B. mlx_put_image_to_window mit eigenem Buffer)

🧭 2.3 Input / Steuerung
Tasten:

WASD: Bewegung

Pfeile: Rotation

ESC & Fensterkreuz: korrekt beenden

Kollisionserkennung mit der Map

♻️ 2.4 Event Loop
Mainloop (mlx_loop) mit:

Render-Funktion

Hook-Funktionen für Input (mlx_key_hook, mlx_loop_hook)
